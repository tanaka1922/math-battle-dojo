# 数学バトル道場

中学数学の問題を、ヒントと解説を使って練習する学習アプリです。公開リポジトリには2,035問の問題データと、Pythonによる問題生成・計算検証のコードを収録しています。

- [アプリを試す](https://math-battle-dojo.vercel.app)
- [EduVest公式サイト](https://eduvest-technologies.pages.dev/)
- [English website](https://eduvest-technologies.pages.dev/en/)

## ファイル構成

ファイルは現在の配置のまま使用します。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 学習アプリの画面と処理 |
| `problems.json` | 問題文・答え・ヒント・解説を含む問題データ |
| `generate_problems.py` | 既存データに問題を追加するPythonスクリプト |
| `validate.py` | 対応する形式の問題を計算検証するPythonスクリプト |
| `errors.json` | 既存の検算結果と誤検知に関する注記 |
| `codex-check.md` | 計算・日本語・難易度を確認するためのレビュー指示書 |
| `vercel.json` | 公開環境の設定 |
| `.gitignore` / `.vercelignore` | Gitと公開環境の除外設定 |

## 問題データの読み方

主な項目は、問題ID（`id`）、カテゴリ（`cat`）、学年（`gr`）、問題文（`q`）、答え（`a`）、ヒント（`h1`・`h2`）、解説（`exp`）です。

2,035問は登録されたデータの件数です。全問の正しさや、学年・難易度の妥当性が独立検証で保証されているという意味ではありません。

## 問題の作り方

`generate_problems.py` は、既存の `problems.json` を読み込み、生成した問題を追加して同じファイルへ上書きします。元のスクリプトは既存217問への追加を前提としており、現在の2,035問をゼロから同じ内容で再生成する手順ではありません。

実行する場合は、元データを保全した別の作業コピーと作業ブランチを用意し、リポジトリのルートで実行します。アプリを利用するだけなら実行不要です。

```sh
python generate_problems.py
```

Python 3の標準ライブラリを使用します。乱数シードは固定されていますが、入力データが異なれば結果も異なります。同じデータへの再実行で追加が重なりうるため、実行前後の件数・ID・問題内容を確認してください。

## 検証の仕方

元データと既存の `errors.json` を保全した作業コピー・作業ブランチで、リポジトリのルートから実行します。

```sh
python validate.py
```

この処理は `problems.json` を読み、`errors.json` を上書きします。既存の手動注記も置き換わるため、実行後は以前の記録との差分を確認してください。

画面には「検算対象」「検算実行」「エラー数」が表示されます。ただし「検算実行」は、対応する処理が例外なく終了した件数であり、正誤を最後まで判定できた件数と同じではありません。

## 既知の制約と確認状況

- 検証コードは一部のカテゴリ・問題文形式に対応しています。未対応の形式、解析できない問題、処理中の例外は確認から漏れる場合があります。
- 演算順序や分数を含む連立方程式などで、検証コードの誤検知が記録されています。
- 既存の `errors.json` には4件のフラグと `false_positive` の注記があります。これは過去の記録であり、このREADME追加時に再実行した結果ではありません。
- 自動検算だけでは、日本語の自然さ、解説との整合、重複、難易度・学年の適切さ、問題文の出典・利用条件は確認しきれません。
- `codex-check.md` はレビュー用の指示書です。レビュー完了や全問合格の証明ではありません。
- 生成・検証スクリプトは現在の作業ディレクトリのファイルを参照します。ファイルを移動して実行する手順は、このREADMEでは扱いません。

このREADME追加では、生成・検証コードの実行、問題データの変更、Drive版との照合を行っていません。今後の検証結果は、対象の版・実行条件・確認できた範囲を添えて、既存記録と区別して記載します。
